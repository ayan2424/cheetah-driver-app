⚡ Quick Summary: Cross-platform Flutter client for Delivery Riders and Warehouse Fulfillment Pickers with digital signature Proof-of-Delivery, barcode scanning, GPS telemetry, and offline sync.

📁 What Is Included in This Package

  • lib/ — Full Dart/Flutter source code organized in clean GetX (MVC-S) architecture.
  • android/ — Complete Android project workspace (Gradle, Android 14/15 Target SDK 34/35, Min SDK 21).
  • ios/ — Complete iOS Xcode workspace (CocoaPods ready, iOS 15.0+ compatible).
  • assets/ — App icons, graphics, and visual asset files.
  • pubspec.yaml — All Flutter dependencies, assets, and font configurations.
  • Help.html — This quick help guide.

🔤 Font(s) & Dependencies Used

  • Fonts: Google Fonts (Poppins / Roboto via google_fonts package).
  • State Management: GetX (get: ^4.6.6).
  • Local Storage & Offline Queue: Hive (hive: ^2.2.3) & GetStorage.
  • Hardware & Camera: mobile_scanner, geolocator, signature, image_picker.
  • Push Notifications: Firebase Cloud Messaging (firebase_messaging: ^15.1.3).

🚀 How to Configure & Run the Project

  1. Step 1: Extract & Open
    Extract the downloaded zip package and open the project in Visual Studio Code or Android Studio.
  2. Step 2: Connect Your Backend URL
    Open lib/utils/constants.dart and change the API domain to your own live server:
    static const String baseUrl = 'https://your-domain.com/';
  3. Step 3: Install Flutter Dependencies
    Open your terminal in the root folder and execute:
    flutter pub get
  4. Step 4: Run on Device or Emulator
    Connect your Android/iOS physical device or start an emulator, then run:
    flutter run
  5. Step 5: Compiling Production Release Builds
    • Android App Bundle (.aab for Google Play): flutter build appbundle --release
    • Android Standalone APK: flutter build apk --release
    • Apple iOS Release (IPA): flutter build ipa --release
